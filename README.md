## Run

## Security notes
- Static site only; no forms, credential collection, database, or server secrets.
- External links opened in a new tab use `rel="noopener noreferrer"`.
- Contact links use `mailto:` and `tel:` and reveal the contact details provided by the portfolio owner.
- Google Fonts is the only external font dependency. For a fully offline deployment, remove the Google Fonts link in `index.html` and use the system fallback fonts.
- For production hosting, configure HTTPS and security headers at the hosting layer (for example, a restrictive Content-Security-Policy, `X-Content-Type-Options: nosniff`, and an appropriate `Referrer-Policy`).
